# 🍕 Clarenz Trattoria - Sitio Web Oficial

Este es el repositorio oficial del sitio web para **Clarenz Trattoria**, una pizzería con la mejor pizza hecha en casa. El proyecto está construido con las últimas tecnologías web para ofrecer una experiencia de usuario rápida, moderna y adaptable a cualquier dispositivo.

---

## ✨ Características Principales

- **Diseño Moderno y Responsivo**: Interfaz limpia y adaptable a móviles, tabletas y escritorio.
- **Componentes Reutilizables**: Construido con React y componentes modulares para fácil mantenimiento.
- **Información de Sedes**: Muestra de forma clara la información de contacto y ubicación de las diferentes sedes.
- **Pedidos Rápidos**: Enlaces directos para realizar llamadas o enviar mensajes por WhatsApp a cada sede.
- **Optimización y Rendimiento**: Desarrollado sobre Next.js para un rendimiento de carga superior y SEO.

## 🚀 Stack Tecnológico

Este proyecto utiliza un conjunto de tecnologías modernas para el desarrollo web:

- **Framework**: Next.js
- **Librería UI**: React
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Iconos**: Lucide React
- **Linting**: ESLint

## ⚙️ Primeros Pasos

Sigue estos pasos para configurar y ejecutar el proyecto en tu entorno local.

### Prerrequisitos

- Node.js (versión 18.x o superior)
- npm o un gestor de paquetes compatible (yarn, pnpm).

### Instalación

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/tu-usuario/clarenztrattoria.git
    cd clarenztrattoria
    ```

2.  **Instala las dependencias:**
    ```bash
    npm install
    ```

3.  **Ejecuta el servidor de desarrollo:**
    ```bash
    npm run dev
    ```

Abre http://localhost:3000 en tu navegador para ver el resultado. La página se actualizará automáticamente a medida que edites los archivos.

## 📜 Scripts Disponibles

En el archivo `package.json` encontrarás los siguientes scripts:

```bash
# Inicia el servidor de desarrollo en localhost:3000
npm run dev

# Compila la aplicación para producción
npm run build

# Inicia un servidor de producción
npm run start

# Ejecuta el linter para analizar el código en busca de errores
npm run lint
```
